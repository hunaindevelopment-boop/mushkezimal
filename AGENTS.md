# AGENTS.md

Noor & Oud is a storefront for a perfume and attar brand, built with TanStack Start and deployed on Netlify.

## Stack

TanStack Start (React 19, TanStack Router v1, server functions) · Vite 7 · Tailwind CSS 4 · Stripe · lucide-react · TypeScript strict.

## Structure

```
public/img/                 Generated product + lifestyle imagery (p-*.jpg products, ctx-*.jpg shared scenes, hero.jpg)
src/data/products.ts        The catalog: products, variants, notes, categories & families, price helpers
src/lib/cart.tsx            CartProvider/useCart — client cart persisted to localStorage (key `noor-oud-cart`)
src/lib/stripe.ts           Server functions: getStripeEnabled, createCheckoutSession (multi-line cart)
src/lib/image.ts            cdn(src, w, h?) → Netlify Image CDN URL (WebP, cover crop when h given)
src/components/             Header (+Logo), Footer, CartDrawer, ProductCard, Stars
src/routes/__root.tsx       Shell: fonts, metadata, CartProvider, Header/Footer/CartDrawer
src/routes/index.tsx        Landing page
src/routes/shop.tsx         Searchable/filterable grid; state lives in URL search params (q, category, family, sort, max)
src/routes/products/$slug.tsx  Product detail page (gallery, variants, add to bag)
src/routes/checkout/        Stripe success (clears the bag) and cancel pages
```

## Conventions & decisions

- **Brand system**: dark "midnight plum" palette with saffron/ember gold accents. Theme tokens (`ink`, `night`, `plum`, `velvet`, `saffron`, `ember`, `rose`, `sand`, `dune`) and fonts (`font-display` Bodoni Moda, `font-sans` Outfit, `font-arabic` Amiri) are defined in `@theme` in `src/styles.css`. The `.arch` class (mihrab arch shape) is the signature image frame — reuse it for product imagery.
- **Images** must be referenced through `cdn()` rather than raw `/img/...` paths so pages never ship full-size originals.
- **Prices** are whole US dollars in the catalog. The checkout server function always re-resolves prices from the catalog by `slug` + `variantId`; never trust client prices.
- **Cart** is intentionally client-side (per-browser session state), not stored in a database.
- Products are addressed by `slug`, not numeric id.
- `routeTree.gen.ts` is generated by the router plugin at build time.

## Env

`STRIPE_SECRET_KEY` — enables checkout. Without it, the bag still works and checkout is shown as unavailable.
